# Motion 创作工作区

入口：工作台顶部 **Motion → 创作工作区 · 代码 / 时间线**。灵感与内容中的“发送到 Motion”会带入文案和制作要求。

1. 填写本期文案、制作要求和总时长，点击“AI 生成动画分镜”。先规划时间线，再逐镜编写 Canvas 2D 动画代码，左侧实时显示回答。
2. 也可点“＋动画代码”独立制作。选中片段后，编辑右侧代码，或描述修改要求后点“AI 重写选中动画”。不要求先完成其他片段。
3. 点“＋视频 / 图片 / 音频 / SRT”选择本地文件。视频原声自动进入混音；SRT 按原时间码进入字幕轨。本期文案可用本机声音生成配音，当前机器支持中文、英文。
4. 时间线支持拖动、两端裁剪、播放头定位、缩放、分割、复制、删除、撤销和重做。右侧可编辑素材入点、时长、位置、尺寸、层级、音量、透明度、文字与颜色。
5. AI 可翻译字幕和动画内的画面文字。配音使用“本期文案”里的文本，并选择对应语言的本机声音；画面翻译不自动替换原声。
6. 编辑会自动保存，也可手动点“保存工程”。“打开本地工程”可恢复工程及最近一次导出结果。
7. 点“导出 MP4”，根据保存版本逐帧渲染并混合声音，显示进度。完成后可以播放和下载；导出失败保留工程和以前的成片。

## 代码与当前范围

动画采用浏览器 Canvas 2D 函数体，参数为 `ctx, time, duration, width, height, assets`。支持任意自写绘制逻辑；不提供 Node、外部模块、DOM 和联网权限。原版 MotionGit 模板制作入口继续保留，任意第三方 `.motion` 工程不能直接当作 Canvas 代码执行。

工程最长 10 分钟、最多 300 个片段；单次 AI 规划最多 24 镜，可继续追加。支持 24/25/30/60 fps、多种横竖画幅。使用本机 Edge 与 FFmpeg 导出。视频编码能否读取取决于本机浏览器支持。

完整参考视频尚未逐项核对，因此没有将未确认的演示细节标记为已实现。

## 排期越界修复

## 导入视频按指示剪辑（2026-11-19）

导入视频后默认进入“按指示剪辑导入视频”，按钮变为“按要求剪辑导入视频”。设置目标时长，填写剪辑要求，即可生成真实源视频片段的入点、时长和顺序，保留原声，按需加入画面短标题。此模式不会把旧的成稿、动画或图片发送给剪辑模型。

默认本地检测镜头变化和静音；勾选允许分析画面后，将少量低清关键帧发送到已配置 AI 服务，原视频文件保留本地。不使用虚构的语音转写。AI 方案格式或时间码错误会自动重试三次，未通过时原时间线保留。

已在用户同意分析关键帧后，将导入的 DSCF0822.MOV（64.064秒）剪成31秒、7个视频片段并保留原声。结果另存为“DSCF0822 · Vlog 剪辑”，原工程保留。实际导出通过音轨、视频轨和时长检查；回归测试153项通过。

## 多段素材与多轨自由编辑

- “导入多个素材”支持一次多选和分批追加。新视频按顺序放入V1主轨，原声分离到A1轨并建立联动。素材库支持插入播放头、顺序追加和拖放到兼容轨道。
- 初剪之后点击“自由编辑轨道”继续操作，AI结果保留为独立片段。旧工程打开时会迁移到可编辑轨道，并保留原有画面叠放关系。
- 支持新增画面、音频、字幕轨，轨道重命名、上下排序、隐藏画面、静音音轨和锁定；预览和导出使用同一套轨道状态。
- 支持跨轨拖动、两端裁剪、吸附、Shift多选、影音联动开关、分割、复制、普通删除和波纹删除。波纹删除会在所有轨道移除相应时段并前移后续内容。锁定的轨道不会被这些编辑修改。
- 方向键微调1帧，Shift+方向键10帧；S分割，Delete删除，Shift+Delete波纹删除，Ctrl+D复制，Ctrl+Z/Ctrl+Y撤销重做。点击并拖动时间尺定位播放头。
- 音频波形从真实源音频采样计算。旧素材可点击“读取真实波形”。视频音量默认移至独立原声轨，避免重复混音。

验收：两段合成视频顺序导入，分割后形成3段视频和3段原声，在6条轨道中跨轨移动并静音，导出4秒成片的视频轨与无音轨状态均正确；实际界面逐帧联动验证通过。回归测试163项通过。

当前支持最多24条轨道、300个片段、10分钟工程，AI视频分析一次最多8个源视频。参考抖音链接仍未能完整读取，未将其中尚未核对的功能标记为全部实现。
