# 自媒体工作台桌面版

双击本目录的 `启动自媒体工作台.cmd`，或桌面的“自媒体工作台”快捷方式。程序以独立窗口运行，自动启动 DSH、自媒体插件和影策服务。关闭窗口会停止本次启动的服务；再次双击会聚焦已打开窗口。

## 全局设置

顶部统一为 56px 单行，灵感画布可在透明栏下拖动；次要功能收进“更多”。全局助手可从顶部开关，所有页面共用对话和开关记忆，较窄窗口中使用浮层。

影策助手可以读取当前项目/画布上下文，执行项目和分集草稿、文字节点、连线的受控编辑。执行前核对页面及版本，保存成功后显示完成；可以通过画布撤销或告诉助手撤销。模型连接必须可用，图片与视频生成仍由原版页面按钮发起。画布操作在隔离数据中完成过创建、编辑、保存、撤销、重复请求和重载验证；实际模型自然语言的理解结果仍需使用者核对。

## 本地素材索引

“资产”和设置中的“本地素材索引”只统计手动导入的本地文件，显示数量、原文件大小及可读状态，没有云盘容量、剩余额度或购买空间。可导入文件或文件夹、分类搜索和预览；文件保留在原位置，不复制或自动上传到云端。

索引元数据保存在 `data/local-assets.json`，它不是素材备份。源文件移动、删除或离线后会显示失效，恢复文件或重新导入后可刷新。浏览器支持的图片、音视频和文本可以在工作台预览；3D 模型等文件先作为索引记录展示。侧栏统计与素材库共用这一份索引。原版已存素材数据仍保留在原数据库中，本次没有删除或迁移。

灵感、内容、排期、影策、复盘、风格共用顶部工具栏。点击齿轮打开“自媒体工作台设置”，可进入通用与成稿、助手模型、风格规则、渠道与模型、创作偏好、本地素材索引、知识技能、插件工具和系统管理。个人信息、积分与用量、通知管理、反馈管理和独立账户资料弹窗已取消，相关页面不再提供桌面入口。成稿和生图参数继续保存在工作台设置；渠道和系统表单使用原版服务实际读写。

影策创作页和管理页移除独立 Logo，重复的语言、账户、主题工具栏由外层工作台入口取代。全局语言和主题会同步到内置页面。创作页点击账户或管理设置链接时，也会打开工作台配置中心；关闭后继续原页面。

## 影策内容

内嵌影策左侧使用常显的 64px 图标导航，创作、短剧、画布、技能、插件、资产和历史均可直接切换。较窄窗口也不会启用抽屉遮罩，主页面可以同时点击和输入。

点击顶部“影策”，直接打开 `open-ai-canvas` 原版前端的本机构建。保留原版创作、短剧制作、自由画布、技能、插件、资产和创作历史等页面，页面中的操作仍由原版后端处理。右侧共用全局助手，可以关闭；切换到其他标签再回来时保留影策页面。

界面不再使用旧的项目/分集/镜头简化草稿页。原先保存在自媒体 JSON 中的本地草稿仍保留在数据文件里，没有自动导入原版数据库。

桌面版由宿主后台认证为同一个本机“工作台用户”。影策不再显示模块内登录、注册、退出入口，创建画布、项目仍通过原版用户权限校验。模型生成仍需要配置原版影策渠道。

## 内容和账号

- 自媒体内容首次从原工作台复制到 `data/dsh/media-desk`，此后两边分别保存。
- DSH 登录凭据首次复制到 `data/dsh/.credentials.yaml`。后续可在独立窗口内管理模型账号。
- 影策使用独立数据库 `data/canvas`，没有迁移旧画布账号和项目。首次启动由桌面宿主自动建立本机工作台用户（首用户为管理员）；内部随机凭据保存在 `data/canvas-identity.json`，不进入页面，也不需要手工填写。后续启动复用同一个用户。
- AI 写作、生图和视频生成仍需可用的模型账号、额度或渠道，本次没有触发付费生成。

## 独立运行

运行环境、插件和前端构建产物都在本目录，不依赖 zdh 主工作台或原安装目录保持运行。

| 服务 | 本机端口 |
| --- | --- |
| DSH | 33280 |
| 影策前端 | 13001 |
| 影策后端 | 18081 |
| 剪辑助手前端 | 13002 |
| 剪辑助手后端 | 自动分配的本机端口 |

服务仅监听本机。端口占用时会提示启动失败，不会终止其他程序。

## 剪辑助手 AutoClip

顶部的「剪辑助手」固定在「影策」和「复盘」之间，嵌入 AutoClip 原版界面，切换页面保留当前编辑状态。桌面工作台负责启动、关闭它的本机服务，不需要另开终端，也不需要另一个工作台账号。

从右上角齿轮进入「通用 AI」，全局助手、影策与剪辑助手共用服务、文字、图片和视频模型。密钥只保存在本机 `data`，页面读取到的配置不包含密钥。修改后会同步影策与剪辑助手，重新打开工作台后全局助手载入新配置。剪辑助手内部不再显示品牌顶栏、服务商连接引导和独立 API 表单；其输出字幕、水印等偏好放在统一设置的「剪辑助手配置」。

已接入 Agnes AI，文字与理解使用 `agnes-2.5-flash`，图片使用 `agnes-image-2.1-flash`，影策视频使用 `agnes-video-2.5-flash`。已验证实际文本回复；未自动生成收费图片、视频或发布内容。本地转写是独立能力，首次处理无字幕视频时仍需安装 Whisper；已有 SRT 可以直接导入。

原版源码与构建位于 `../autoclip`，专属 Python 和 FFmpeg 位于 `../.local-runtimes`，项目、设置和数据库保存到本目录的 `data/autoclip`。这些目录需一同保留；既有影策和工作台数据保持原位。AutoClip 使用 MIT 许可，许可证在 `../autoclip/LICENSE`；FFmpeg 许可随其下载包保留。

维护时，在 `../autoclip/frontend` 执行 `npm ci`，再运行本目录的 `build-autoclip.ps1` 更新工作台专用前端。普通上游构建保留原版独立设置，不用于本桌面版本。`verify-autoclip.py` 在日志下的独立目录验证示例项目、真实视频切割、项目编辑接口及来源校验，不修改正式项目。

`runtime` 保存运行环境，`data` 保存用户数据，`logs/desktop.log` 保存诊断日志。备份时关闭程序后复制 `data`；目录中含登录凭据，不要上传公开仓库。

## 维护

`setup.ps1` 用于本机准备和更新插件副本，保留已有用户内容和设置。需要在工作台关闭时执行。影策前端由原仓库的 Vite 构建到 `runtime/canvas-web`，桌面版使用本机静态服务，不需要运行 Vite 开发服务。

运行 `build-canvas.ps1` 更新影策前端，它会设置桌面专用的统一身份构建开关。原仓库普通构建保留原版账号机制。若身份文件丢失但数据库已有账号，程序会停止并提示迁移，不会自动接管其他账号；备份时请将整个 `data` 目录一起保存。这个身份集成适用于当前单人桌面版，不作为多人服务器的单点登录服务。

当前是本机可运行的桌面目录版，尚未制作安装向导。搬到其他电脑前需要重新登录账号，并验证运行环境和模型渠道。
